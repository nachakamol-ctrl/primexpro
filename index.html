FAQ

คำถามที่เจ้าของธุรกิจมักอยากรู้ก่อนเริ่มโปรเจกต์

ยังไม่มีโลโก้หรือแบรนด์เลย เริ่มได้ไหม?

ได้ และหลายกรณีการเริ่มจากศูนย์ช่วยให้วางระบบได้ง่ายกว่า เพราะเราสามารถเริ่มจาก Positioning และ Target Customer ก่อนสร้างภาพลักษณ์

มีโลโก้อยู่แล้ว จำเป็นต้องทำใหม่ไหม?

ไม่จำเป็น เราจะประเมินก่อนว่าสิ่งเดิมยังเหมาะกับ Positioning ใหม่หรือไม่ บางโครงการเพียงจัดระบบและพัฒนา Visual Direction เพิ่มก็เพียงพอ

PRIMEX PRO รับทำแค่ Packaging หรือ Website อย่างเดียวไหม?

รับได้ แต่เราจะถามโจทย์ธุรกิจก่อนเสมอ เพื่อให้สิ่งที่ออกแบบเชื่อมกับเป้าหมายการขายและภาพลักษณ์ ไม่ใช่เป็นชิ้นงานแยกส่วน

ราคาในเว็บไซต์คือราคาสุดท้ายหรือไม่?

เป็นราคาเริ่มต้นเพื่อให้เห็นระดับงาน ราคาจริงขึ้นอยู่กับ Scope, จำนวน Deliverables, ความซับซ้อน และบริการภายนอกที่เกี่ยวข้อง

รวมค่าพิมพ์ กล่อง ผลิตบรรจุภัณฑ์ หรือยิงโฆษณาหรือไม่?

ไม่รวมโดยอัตโนมัติ ค่า Supplier และ Media Spend จะแยกออกมาอย่างโปร่งใส เพื่อให้ลูกค้ารู้ว่าจ่ายค่าความคิด ค่างานออกแบบ และค่าผลิตส่วนใดบ้าง

แก้ไขงานได้กี่ครั้ง?

จำนวนรอบแก้ไขจะกำหนดใน Proposal ของแต่ละ Package/Project เพื่อให้ Timeline และ Scope ชัดเจนตั้งแต่เริ่มต้น

ถ้ายังไม่แน่ใจว่าควรซื้อแพ็กเกจไหน?

ไม่ต้องเลือกเองก่อน ใช้ Free Initial Project Review หรือส่ง Project Intake มาให้เรา แล้วเราจะเสนอจุดเริ่มต้นที่เหมาะสมให้
